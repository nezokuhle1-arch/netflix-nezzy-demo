# Netflix Landing Page Clone

A fully responsive Netflix-inspired landing page built with HTML and CSS.

## 🎯 Project Overview

This project recreates the Netflix South Africa landing page as part of my assignment for ZAIO Full Stack AI Engineering course. It demonstrates modern web development skills including semantic HTML, responsive design, and interactive UI components.

## ✨ Features

- **Hero Section**: Eye-catching banner with email signup CTA
- **Trending Now Carousel**: Horizontally scrollable movie cards with ranking numbers
- **Video Integration**: Embedded trailer in the features section
- **Interactive FAQ**: Collapsible questions using HTML `<details>` and `<summary>`
- **Mobile Responsive**: Optimized for desktop, tablet, and mobile devices
- **Language Selector**: Multi-language dropdown in navigation
- **Netflix Branding**: Dark theme with authentic Netflix color scheme

## 🛠️ Technologies Used

- HTML5 (Semantic markup)
- CSS3 (Flexbox, Grid, Media Queries)
- Google Fonts (Inter)
